# Borsa Istanbul Review - submission requirements

Retrieved from the Elsevier Guide for Authors, 2026-08-18.

## Review model

**Double anonymized.** Two files are required:

- **Title page (separate file):** title, author names, affiliations,
  acknowledgements, Declaration of Interest statement, and full corresponding-
  author address including email.
- **Anonymized manuscript:** the entire body -- *including references, figures,
  tables and acknowledgements* -- must contain no identifying information.

Note: the page also carries generic Elsevier boilerplate describing a single
anonymized process. The journal-specific "Double anonymized review" section is
the operative one, and it is unambiguous. Prepare for double anonymized.

This has a direct consequence for us: self-citation, the GitHub repository URL,
and any Vietnamese institutional affiliation must be stripped from the
manuscript body and held in the title page file. A public data repository link
would deanonymize the submission and has to be handled as a masked citation.

## Manuscript requirements

| Item | Requirement |
|---|---|
| Abstract | Concise, factual, standalone. No references. No uncommon abbreviations. |
| Keywords | **Maximum 6.** American spelling. Avoid 'and'/'of', plurals, multiple concepts. |
| Format | Single-column. No justification, no hyphenation. Bold/italic/sub/superscript fine. |
| Equations | Editable text, not images. Variables italic. Number displayed equations. |
| Footnotes | Sparingly, numbered consecutively. Not in the reference list. |
| Datasets | Cite in text and reference list, prefixed `[dataset]`. |

No explicit word limit is stated in the guide.

## Required declarations

- **Declaration of interest** -- in the title page file under double anonymized
  review. If none: "Declarations of interest: none."
- **Declaration of generative AI in scientific writing** -- required if AI tools
  were used in manuscript preparation, as a new section immediately before the
  reference list. Does not apply to basic grammar, spelling or reference tools.
  AI tools must not be listed as authors. The wording and whether it applies is
  the authors' call.
